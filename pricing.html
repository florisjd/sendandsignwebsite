Install guide · 5–10 minutes · zero PowerShell

Live in five steps.

You'll need the SharePoint Administrator role (plus a Global or Cloud Application Administrator for the one-time consent). Before you start, send us your Microsoft 365 tenant ID so we can onboard it.

1

Upload the app package

SharePoint Admin Center → More features → Apps → Manage apps. Upload spfx-send-and-sign.sppkg and choose Enable this app and add it to all sites — or enable it on one pilot site.

2

Consent & approve API access

A Global Administrator opens the one-click consent link we provide. Then approve the four delegated permissions under Advanced → API access.

3

Add the web part

On any modern page, add the SendAndSign web part (under Advanced) and publish.

4

Automatic first-launch setup

When a site owner first opens the page, the tracking list, settings list and archive folder are created and a green banner confirms it.

5

2-minute smoke test

Send a test document to your personal email, verify the code, sign — and watch _Signed.pdf appear next to the original within about 30 seconds.

Upgrades keep everything

Upload a newer package and choose Replace. Pages, tracking history and signed files stay intact. Removing the app leaves all your data in SharePoint.
