FAQ

Questions we hear from IT, legal and sales.

Do my clients need a Microsoft account?

No. External signers open a single-use link, verify a 6-digit code sent to their email, and sign in a standalone portal. They never see a Microsoft login screen and never receive any access to your SharePoint.

Where do signed documents end up?

Back in SharePoint, in the exact folder the original came from, saved as {OriginalName}_Signed.pdf. The original file is never modified.

What kinds of documents can we send?

Simple contracts and everyday agreements — quotes, proposals, NDAs, service agreements, HR agreements and multi-party commercial sign-offs — under the Electronic Transactions Act 1999 (Cth) s 10. Send & Sign is not intended for deeds, witnessed instruments, wills or statutory declarations.

Which file types are supported?

PDFs and interactive HTML proposals. Word, Excel and PowerPoint files are not accepted directly — save them as PDF first (Office files appear in the picker with a helpful "save as PDF first" hint).

How long does installation take?

Most SharePoint administrators finish in 5–10 minutes: upload the .sppkg, approve four delegated permissions, add the web part to a page. Tracking lists and the archive folder are created automatically on first launch.

What happens if we uninstall it?

The web part stops running immediately, and every original, signed copy, tracking list and audit archive stays in your SharePoint tenant.
